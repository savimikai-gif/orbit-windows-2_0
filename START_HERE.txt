ORBIT 3.1 — WINDOWS SOURCE / GITHUB ACTIONS BUILD
==============================================

IMPORTANT: THIS ZIP IS THE SOURCE PACKAGE, NOT A PRE-COMPILED .EXE.
The HTML/JavaScript interface was smoke-tested in Chromium preview mode.
Windows-specific microphone, audio, installer and updater behavior require
building/testing on a real Windows PC; do not publish as stable before testing.

YOU DO NOT NEED FIREBASE OR SUPABASE. NO ACCOUNT CREATION.

FASTEST WAY TO BUILD (using your existing orbit-windows GitHub repository)

  1. Extract this ZIP.
  2. Open the ORBIT_3_1 folder.
  3. Upload its CONTENTS to the ROOT of your orbit-windows repository,
     replacing matching files/folders. Do not add an extra ORBIT_3_1 subfolder.
     On GitHub, .github/workflows/build-windows.yml must be at the repo root.
     Remove any old Web/src/cloud-sync.js and Web/src/cloud-config.js from
     the repo if they still exist. They are no longer imported.
  4. Commit to branch main.
  5. Go to GitHub > Actions > Build ORBIT 3.1 for Windows > newest run.
  6. After a GREEN build, open its Artifacts section, download
     ORBIT-3.1-Windows, and extract the ZIP.
  7. Run ORBIT_3_1_Setup.exe on Windows. Alternatively run extracted ORBIT.exe.

IF THE BUILD FAILS: Open the red Actions run, select the failing step,
and copy the FIRST C# build error (don't send just the warnings).

ON FIRST RUN
  * Notes tab: write notes; edits autosave to %LOCALAPPDATA%\ORBIT\notes.json
  * Settings > Voice Activation > Push to talk: grants microphone access
    when Windows supports an installed speech recognizer.
  * Settings > Voice Activation > Enable hands-free: explicitly opts into
    Hey ORBIT detection. Use Microphone off to stop listening.
  * Speech language recognition engine needs an installed Windows speech
    recognizer. If English (US) recognition is missing, add English speech
    support under Windows Settings > Time & language > Language & region.
    Romanian recognition depends on installed Windows speech availability;
    not all Windows editions offer ro-RO recognition via System.Speech.
  * Settings > Windows integration: Show corner performance widget.
  * Settings > Automatic updates: enter your own public GitHub OWNER/REPO.

FUTURE UPDATES
  1. Publish a GitHub Release tagged v3.2.0 (or higher).
  2. Attach the installer ORBIT_3_2_Setup.exe AND the adjacent
     ORBIT_3_2_Setup.exe.sha256 generated by your build workflow.
  3. Update the app version constants when making the next build.
  4. In ORBIT Settings > Check for updates. ORBIT downloads and verifies
     the SHA-256 checksum, then asks Windows to run your installer.
  5. Do not delete %LOCALAPPDATA%\ORBIT during upgrades.

IMPORTANT LIMITATIONS
  * The bundled voices are the voices installed on the user's Windows PC.
    Natural-sounding voices appear automatically only if Windows provides
    them. Universal hosted AI/neural voices cannot be safely distributed
    without a developer-managed HTTPS speech service and its running costs.
    NEVER embed a private Azure Speech/API key in a public ORBIT.exe.
  * The wake-word is a speech-recognition grammar, not a trained keyword
    model; recognition and false positives must be tested on real machines.
  * Brightness control works on compatible laptop/internal displays.
    Many external monitors cannot be controlled this way.
  * CPU/RAM stats are Windows native; GPU sampling is not included.
  * This package retains the existing Windows WebView2 runtime dependency.
    On Windows 11 it is usually present; install it if Windows says missing.
  * The update checksum protects against corrupted downloads but not a
    compromised publisher account. Digitally sign releases for public use.

DEVELOPER BUILD (on Windows with .NET 10 SDK)
  Double-click BUILD_WINDOWS.bat. Inno Setup 6 is optional for installer.

CONTAINS: Native/*.cs, Web/*, Installer/ORBIT.iss, GitHub Actions workflow.
ORBIT personal data under %LOCALAPPDATA%\ORBIT is not installed/erased
by the .iss installer. Existing WebView2 profile is kept between releases.
